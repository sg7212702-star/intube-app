# 📸 InTube - Real-Time Instagram Clone

> 100% Real-Time System | Instagram-like Algorithm | Modular Architecture

InTube is a real-time social media app like Instagram, built with Firebase. No demo, all real data, real likes, real-time feed ranking.

### ✨ Features - 100% Real System
- **Real-Time Feed** - Firestore `onSnapshot` - Post karte hi feed me ayega
- **Instagram Algorithm** - `Score = (Likes x 2) + (Comments x 3) + (Shares x 4) - Time Decay`
- **Modular System** - Har feature ki alag file, HTML ko chedna nahi padta
- **Stories (24h)** - 24 ghante me auto-expire
- **Like / Comment / Share** - Real-time score update
- **Upload System** - Image / Video / Reels
